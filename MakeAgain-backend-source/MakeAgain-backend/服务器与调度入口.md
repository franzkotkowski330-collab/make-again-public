## 从哪里看 Agent 调度

| 入口 | 作用 |
| --- | --- |
| `api/routes.py:64` | `/api/chat` 请求入口，调用陪伴 Agent。 |
| `agent/companion.py:192` | 按当前陪伴对象的类型，分流到分手、亲友离世、宠物离世或通用聊天引擎。 |
| `agent/breakup.py`、`agent/loved_one.py`、`agent/pet.py` | 三类具体场景 Agent。 |
| `memory/jobs.py:7` | 把后台任务意图挂到当前事务。 |
| `memory/jobs.py:15` | 将任务持久化入队，并按去重键避免重复插入。 |
| `memory/b07_models.py:95` | `Job` 模型，表名 `durable_jobs`；记录任务类型、状态、次数、到期时间和去重键。 |
| `admin_cli.py:27` | Worker 领取到期任务，按 `kind` 分发执行。 |
| `admin_cli.py:138` | Worker 命令行及持续轮询主循环。 |
| `api/subscriptions.py:198` | 管理员安排已获用户授权的微信订阅消息任务，支持延迟发送。 |
| `api/subscriptions.py:210` | 管理员查询任务状态。 |

后台链路：业务入口 → `enqueue()` → 原业务事务中 `flush_intents()` → `durable_jobs` → Worker `run_one()` → 对应处理函数。

Worker 支持的任务：

- `memory`：记忆提取与写入，见 `memory/async_write.py`。
- `portrait`：画像合并，见 `memory/portrait.py`。
- `report`：访谈报告，见 `agent/async_report.py`。
- `weekly`：周报，见 `agent/weekly.py`。
- `summary`：历史会话摘要，见 `agent/history_summary.py`。
- `message`：微信订阅消息，见 `gateway/messages.py`。

Worker 根据 `due_at` 领取 `pending`、`retry` 任务，用 SQLite 写锁保护领取过程。可重试失败最多执行 3 次，并设置指数退避；消息发送结果未知时记录 `unknown`，避免自动重复发送。持续循环还会定期查询已有未决订单。
