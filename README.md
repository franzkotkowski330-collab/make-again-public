## 打开与核验

用微信开发者工具打开此目录，点击“编译”。登录页动效结束后保持显示，只保留底部“微信登录”。点击后调用原生 `wx.login`，取得临时凭证后进入首页；首次进入自动弹出浅紫信封与主创信，点击“开始”后信件收进收藏。底栏包含首页、聊天、收藏、我的。

当前前端采用 TDesign 小程序组件。登录页保留 Parisienne 花体与柔光动画，为花体外伸笔画增加留白，确保 Make Again 完整显示；下方小字采用霞鹜文楷与 1.8 秒从左向右显现动画，字体随项目离线打包。页面使用原生 WXML、WXSS、JS、JSON。`wx.login` 仅取得临时凭证，微信账号后台仍未接入，尚未建立经过服务端校验的账号登录态；点击后进入现有本地体验，记录仍保存在本机。详情见 `docs/登录页调整核验.md`。

离线预览：双击 `Make-Again-登录页预览.html`。预览复用原生登录页的 WXML 与 WXSS，HTML 中的登录按钮演示页面跳转，无法在浏览器取得微信凭证。重新生成：`node scripts/build-html-preview.cjs Make-Again-登录页预览.html`。

1. 在聊天页选择“暂不开始”，确认回到首页；此时没有创建游客或保存倾诉。
2. 再进入聊天，阅读并同意说明后写一句话，点击“保存”。当前不会收到 AI 回复。
3. 重新编译，检查信件不再自动弹出、聊天历史仍保留。
4. 进入“我的 → 陪伴信息”，填写四类信息并保存；任一字段可留空或暂不分享。
5. 进入收藏，切换信件／物品／照片／记忆；主创信可重读，其他栏目显示真实空状态。

主创信沿用旧版已存在的正文，仅统一品牌与团队称谓。没有新增主创经历。主题来源为云光实验室的第一个方案：云雾光晕＋云朵蓝紫，以原生 WXSS 渐变实现。

## 当前功能与限制

已完成原生四 Tab、首次信件、游客同意、本地文字保存与恢复、四字段手动建档、收藏四栏目和本地记录说明。

本阶段只有本机数据，没有服务器、真实 AI 回复、自动建档、语音、图片上传、情绪分析、长期记忆、漂流瓶投递、结束仪式或账号迁移。没有 14 天自动删除机制；模拟器与真机的数据各自独立。未接入的能力不会显示为已成功。

建档按本轮用户确认仅使用：离别类型、关系对象、当前困扰、陪伴期待。四类均可留空或拒答，优先于原 MVP 文档中建议的九类字段。

## 本地开发边界

- 页面使用 `utils/service.js`，当前实现位于 `utils/local-service.js`；统一缓存读写位于 `utils/storage.js`。
- 使用 TDesign 小程序版的 Button、Cell、Tabs、Icon、Empty、Dialog 组件，结合微信原生输入组件与 `tabBar`；没有 WebView 或浏览器页面。
- 文字、建档、收藏数据关联游客与旅程标识。未同意时，只有作者信的已读标识可以持久化。
- 缓存键为 `make_again_local_v1`。缓存损坏时停止写入，保存失败时保留聊天草稿；拒答字段保存后清除其旧值。
- `miniprogram-automator` 只用于电脑上的开发验收，不被客户端引用，已从小程序打包范围排除。

## 验证命令

首次安装依赖后，在微信开发者工具“工具 → 构建 npm”，生成 `miniprogram_npm/tdesign-miniprogram`。也可使用 CLI 的 `build-npm` 命令。`app.json` 没有启用 `style: v2`，避免其默认按钮尺寸覆盖 TDesign 样式。

```powershell
npm.cmd run check
npm.cmd test
node scripts/verify-html-preview.cjs
```

开发者工具自动化接口已在此电脑测试成功。重新连接时可执行：

```powershell
& 'C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat' auto --project 'D:\商赛\make again 手搓' --auto-port 9420 --trust-project --lang zh
npm.cmd run test:devtools
node scripts/verify-login-native.cjs
```

原生登录页专项脚本核对字体与布局、动效后停留、唯一微信入口、失败重试、真实微信凭证获取后的跳转和现有缓存一致性，不写入测试聊天。信件流程脚本中的登录凭证使用测试桩，不代表账号验证。此前的一期验收脚本保留用于历史参考，其选择器不再适用于改版后的组件。
